# Splatcraft NeoForge

Splatcraft NeoForge 是将 Splatcraft 重写到 Minecraft 1.21.1 NeoForge 的模组，加入墨汁武器、鱿鱼形态、染色方块与对战场地工具。

Splatcraft NeoForge is a Minecraft 1.21.1 NeoForge rewrite of Splatcraft, adding ink weapons, squid form, colored blocks, and arena tools.
